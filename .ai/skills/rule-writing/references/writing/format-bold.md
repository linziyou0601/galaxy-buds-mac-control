# 粗體使用

粗體只標示結構化標籤，讓讀者掃描時能快速定位欄位。本檔的條目套用在 markdown 與 mdx。

## 標籤位置

粗體只用在區塊開頭的標籤與單獨一行的子標題。下列位置是標籤位置：

- 段落、清單項或引言開頭的粗體，例如 `- **動作**：執行驗證`、行首 `**多選允許**：`
- 表格第一格開頭的粗體，例如 `| **匯入** | 匯入流程 |`
- 取代 H4 的子標題：單獨一行的 `**X**`，前面可以有一個狀態符號
- `<div>` 加重語氣區塊內的粗體

## 句中強調

句中要強調的詞用全形引號「X」標示，或直接寫成普通文字。lint 以規則「句中粗體」列出標籤位置以外的粗體，粗體在句中強調一個詞時判為違規，依下列寫法改寫：

- 引導句寫成普通敘述句。
- 表格第一格以外的格子寫普通文字。
- 整句警告放進加重語氣區塊。
- 連結文字與表頭交給 Markdown 本身的樣式。
- 狀態與 enum 名稱使用行內 code，例如 `running`、`blocked`。

### 成因

模型會把句中的專有名詞、縮寫或形容詞加粗，讀者的視線被拉到不重要的地方。

### 改寫前

```text
它整合了 **OKR（目標與關鍵成果）**、**KPI（關鍵績效指標）**，以及 **平衡計分卡（BSC）**。
```

### 改寫後

```text
它整合了 OKR、KPI 與平衡計分卡。
```
