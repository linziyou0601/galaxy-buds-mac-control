# 產物與段落邊界

圖、表、code block、編號清單與項目清單都是前文說明的結構化產物。每個產物收束它前面的說明，基本形態是「說明 → 產物」。本檔的條目套用在 markdown 與 mdx。

## 閱讀單元

產物前的說明交代用途、閱讀方式與判定範圍，產物本身列出完整內容。多個產物時，每個產物與自己的說明組成一個閱讀單元，依閱讀順序交錯排列。產物之後若還有文字，那段文字開啟下一個獨立主題或下一段獨立說明，可以用 H2、H3 標示，也可以直接開新段落：

```text
說明 → 產物
說明 → 產物 → ### 下一個獨立主題 → 新說明
說明 → 產物 → 下一段獨立說明
說明產物 1 → 產物 1 → 說明產物 2 → 產物 2
```

下列排法把同一組資訊拆散，讀者得前後對照才拼得回來，改成上面的形態：

```text
說明 1 → 產物 → 補述說明 2
產物 → 移位的說明 1
說明 1 → 說明 2 → 產物 1 → 產物 2
```

### 判定候選

lint 以規則「產物之後的補述」列出產物之後、下一個標題之前，沒有以冒號引出下一個產物的段落。這段文字補述前一個產物時判為違規，把內容移進產物前的說明，或寫進產物本身。這段文字開啟新主題時判為誤報，依據寫出新主題是什麼。
