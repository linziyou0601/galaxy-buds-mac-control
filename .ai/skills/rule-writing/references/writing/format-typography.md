# 中英排版

<!-- 改寫自 https://github.com/sparanoid/chinese-copywriting-guidelines（中文文案排版指北，MIT License） -->

中文與英文、數字混排時，空白與標點的寫法決定讀者能不能一眼分出詞的邊界。本檔的條目套用在全部格式，行內 code 與英文單字同樣看待。

## 中英之間的空白

中文與英文、行內 code 之間加一個半形空白，詞的邊界才清楚，例如「在 LeanCloud 上，資料儲存圍繞 `AVObject` 進行」。連結文字與前後的中文之間同樣加空白，例如「請 [提交一個 issue](#) 並分配給相關同事」。lint 以規則「中英之間沒有空白」檢查。

## 中文與數字之間的空白

中文與數字之間加一個半形空白，例如「今天出去買菜花了 5000 元」。lint 以規則「中文與數字之間沒有空白」檢查。

## 數字與單位之間的空白

數字與單位之間加一個半形空白，例如「寬頻有 10 Gbps，硬碟有 20 TB」。度數與百分比不加，例如「角度為 90° 的角，新 MacBook Pro 有 15% 的 CPU 效能提升」。

lint 以規則「數字與單位之間沒有空白」列出。命中時先確認單位不是度數或百分比，再確認命中的是數字接單位而不是型號或版本，例如 `H5` 元件名、`v2ms` 這類名稱照原樣保留。

## 全形標點旁的空白

全形標點與其他字元之間不加空白，例如「剛剛買了一部 iPhone，好開心！」。全形標點本身已經留有間距，前後再加空白會讓版面出現大洞。lint 以規則「全形標點旁的空白」檢查。

## 重複標點

同一個標點不重複，例如「德國隊竟然戰勝了巴西隊！」不寫成「！！」。lint 以規則「重複標點」檢查。

## 中文句子的標點

中文句子用全形標點。lint 以規則「中文句子用半形標點」列出，命中時確認標點在中文句子裡。標點在夾著的英文句子或程式寫法裡時判為誤報，程式寫法放進行內 code 後 lint 就會略過。

## 數字的寫法

數字一律用半形，例如「這件蛋糕只賣 1000 元」。lint 以規則「全形數字」檢查。

## 英文句子的標點

整句英文或書名這類特殊名詞，標點跟著英文寫成半形。lint 以規則「英文句子用全形標點」列出，寫法如下：

```text
賈伯斯那句話是怎麼說的？「Stay hungry, stay foolish.」
推薦你閱讀 Hackers & Painters: Big Ideas from the Computer Age，非常的有趣。
```

## 專有名詞的大小寫

專有名詞依官方的大小寫書寫，例如 GitHub、JavaScript、TypeScript、Node.js，寫法登記在 `references/tables/lex-english.tsv`。lint 以規則「專有名詞大小寫」列出，命中時先判斷寫的是不是名稱：程式識別字、套件與儲存庫名稱放進行內 code，標題與英文句首的大寫照原樣保留。

## 縮寫

縮寫用讀者熟悉的寫法，例如 HTML5、Next.js、React，不寫成「h5」「nextjs」「reactjs」。不道地的縮寫登記在 `references/tables/lex-avoid.tsv`，lint 以規則「不道地的縮寫」列出，命中時判斷讀者是否熟悉這個寫法。
