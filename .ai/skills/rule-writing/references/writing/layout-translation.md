# 翻譯指引

翻譯依目標語言語序重寫，來源檔、語言版本、鍵集合與驗證方式依 [project-policy](../project-policy.md)。翻譯腔的成因與改寫見 [prose-technical](prose-technical.md) 的「翻譯腔」。下列標題對應適用於有維護平行文件的內容。

## 標題對應

兩個語言版本的 `#`、`##`、`###` 標題逐一對應，同一節在兩個版本落在同一個位置。

## code block 的翻譯

code block 保持原樣，只翻譯其中的註解。

## 連結路徑

連結路徑保持原樣，包含檔名、i18n 鍵與程式識別子。

## 對齊檢查

翻譯完成後，依專案慣例檢查語言版本的鍵集合、標題、連結與插值參數，執行專案既有的驗證指令。
