# 文件收錄政策

根目錄文件依讀者任務分工，同一完整事實由一份文件維護。

| 文件 | 收錄內容 |
|---|---|
| `README.md` | 產品、支援範圍、執行入口與文件導航 |
| `AGENTS.md` | 文件權威、技能路由與協作權限 |
| `CONTRIBUTING.md` | 開發環境、建置、測試、架構、功能擴充與驗收 |
| `DESIGN.md` | macOS 面板樣式、互動、素材與可存取性 |
| `THIRD_PARTY.md` | 上游程式、授權、圖片來源與重製條件 |

技能的參考文件放在各自 `references/`，由 SKILL.md 連結。建置產物位於 `dist/`，永久文件留在原始碼目錄。
