# 設計準則型錄

`references/design/` 是寫作檢查的準則：設計原則、引擎的演算法約定與規則的修改流程。維護機讀定義表與引擎時依這些準則判斷，寫文件時依 `SKILL.md` 與 `references/writing/`。

## 條目索引

| 檔案 | 內容 |
|---|---|
| [principles](design/principles.md) | 總則：lint 與 LLM 的分工、層級、判斷路徑、格式、版面與文風三個面向、規則寫在表、被討論的寫法 |
| [engine](design/engine.md) | 引擎準則：管線、解析與遮罩、路徑設定與文風、層級的決定、檢查範圍、詞表比對、術語與重複的發現項目 |
| [amendment](design/amendment.md) | 規則修改流程：修改步驟、依語料決定層級與回歸量測 |
