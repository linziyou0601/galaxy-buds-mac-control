# 交流殘留

聊天介面的對話語氣被直接帶進文件。這些句子原本是助理對使用者說的話，放進文件後，讀者會突然讀到一句對話。

## 聊天回覆殘留

### 偵測訊號

希望這對你有幫助、當然！、沒問題！、你說得完全對！、需要我……嗎、要不要我舉例、要繼續嗎、讓我知道、以下是一份……

### 成因

這些是聊天回覆的開場或收尾，貼進文件後暴露了文件是對話紀錄的貼上結果。

### 改寫前

```text
以下是資料匯出流程的說明，希望對你有幫助！如果需要我展開任何步驟，請讓我知道。
```

### 改寫後

```text
匯出流程從選擇日期範圍開始，選定後系統列出可匯出的資料表。
```

## 知識截止免責與臆測填空

### 偵測訊號

截至〔日期〕、根據我的訓練資料、雖然具體細節有限、根據現有資訊、相關細節未公開、據推測、很可能

### 成因

模型找不到來源時，會先寫一句「這方面資訊不多」，再補一段看似合理的內容填空。技術文件中，查不到的事寫成待確認的阻塞事項，查得到的事附上來源。

### 改寫前

```text
雖然關於這個參數的具體說明在現有文件中不多，但它很可能用來控制重試的次數。
```

### 改寫後

```text
`retry.max-attempts` 控制重試次數，定義於 `RetryProperties`。
```

查不到來源時：

```text
`retry.backoff` 的用途尚待確認，已列入阻塞事項。
```

## 諂媚語氣

### 成因

模型傾向用讚美開場，讓讀者感覺被肯定，內容卻沒有增加。

### 改寫前

```text
好問題！你說得完全對，這確實是個複雜的議題。你提到的權限因素也是個很好的觀點。
```

### 改寫後

```text
權限設定會影響這個結果：只有具備檢視權限的使用者看得到這個頁籤。
```
