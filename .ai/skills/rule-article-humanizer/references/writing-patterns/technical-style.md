# 技術文體

開發者文件、README、skill 與程式註解的讀者是來完成一件事的。他們要的是一次讀懂的直述句：做什麼、在哪裡做、做完會怎樣。本條目收錄技術文字最常出現的平均值痕跡。

## 否定補述與「不 X，只 Y」

### 偵測訊號

- 正面事實之後接「，不需要……」「，不必……」「，不是……」「，而不是……」「，無須……」
- 「不 X，只 Y」「只 Y，不 X」「不處理 X，只負責 Y」
- 「不是 A，而是 B」「不只是 A，更是 B」

### 成因

模型寫完一個事實後，習慣再補一句它「不是什麼」，好像在預先回答讀者沒有問的問題。讀者讀到否定句時，得先想像那個被否定的選項，再把它丟掉，閱讀成本變高。範圍限制寫進條件本身，讀者就只需要記住一件事。

否定句適合三種情況：規則條文本身就是禁令；否定的內容就是行為結果，例如「刪除後無法復原」；省略這句否定，讀者會做出不可逆的錯誤操作。

### 改寫前

```text
選項來自所選的項目，不需要自己猜。
欄位只在儲存時檢查，不在輸入時檢查。
這個頁面不是用來新增資料的，而是用來查詢歷史紀錄。
```

### 改寫後

```text
選項取自目前選取的項目。
系統在按下儲存時檢查欄位。
這個頁面用來查詢歷史紀錄。
```

## 名詞片段與敘述句

### 偵測訊號

說明欄、tooltip、表格說明格、欄位說明只寫名詞或名詞片段，例如「語言欄位」「顯示名稱設定」「狀態」。

### 成因

模型把說明欄當成標籤再寫一次。讀者打開 tooltip 或說明格，是想知道這個欄位做什麼、怎麼填。名詞片段只告訴讀者欄位叫什麼，這件事欄位名已經說了。名詞片段只用在標籤本身。

### 改寫前

```text
| 顯示名稱 | 各語系名稱 |
```

### 改寫後

```text
| 顯示名稱 | 選單在介面上顯示的名稱，每個語系各填一份，使用者切換語言後看到對應語系的名稱。 |
```

## 翻譯腔

### 偵測訊號

- 中文譯文：「進行……」「對……進行……」「被……」「一個……的」「基於」「針對」「作為」堆疊；長串修飾語放在名詞前；句子照英文子句順序排列
- 英文譯文：照中文語序排列子句、重複主詞、`It is the place where...`、`Please kindly...`、把中文的四字詞逐字翻出

### 成因

模型翻譯時傾向逐句對應原文，保住原文語序。讀者看得出這段是翻過來的，因為句子不像以該語言直接寫成。譯文的目標是讓讀者讀到同樣的資訊，句構依目標語言重寫，術語與 UI 字串則與該語言的介面一致。

### 改寫前（中文）

```text
系統將會對使用者所輸入的資料進行一個驗證的動作。
```

### 改寫後（中文）

```text
系統會驗證使用者輸入的資料。
```

### 改寫前（英文）

```text
In this page, it is the place where you can carry out the setting of the menu.
```

### 改寫後（英文）

```text
Use this page to configure the menu.
```

## 簡中與繁中用語

### 偵測訊號

簡中文字出現台灣用語，或繁中文字出現大陸用語。常見對照：

| 繁中（台灣） | 簡中（大陸） |
|---|---|
| 資料、訊息 | 数据、信息 |
| 使用者 | 用户 |
| 預設 | 默认 |
| 建立 | 创建 |
| 設定 | 设置 |
| 儲存（存檔） | 保存 |
| 儲存（倉儲） | 存储 |
| 支援 | 支持 |
| 檔案 | 文件 |
| 程式 | 程序 |
| 帳號 | 账号 |

### 成因

簡繁轉換工具只換字形，詞彙仍是原來的地區用語。讀者一眼就看得出是轉出來的。產品介面已有 i18n 字串時，手冊用詞以該語系的 i18n 為準，兩邊說法才會一致。

### 改寫前

```text
在使用者资料页面建立新的设定后储存。
```

### 改寫後

```text
在用户信息页面创建新的设置后保存。
```

## 同一件事拆成多句

### 偵測訊號

同一件事的條件、動作與結果被切成三四個短句；一整段每句都很短；為了避開分號，把並列句也拆成獨立短句。

### 成因

「兩個獨立陳述用句號分開」這條規則被套用過頭時，模型會把原本屬於同一件事的子句也切開，讀者得自己把這些短句拼回一件事。拆句以語意單位為準：同一件事寫在同一句，用逗號串接條件、動作與結果，彼此獨立的事才分句。標點的分工依 Skill `/rule-documentation` 的 DOC-FMT-05。為了製造張力而連續堆疊的宣告句，見 [filler-rhetoric](filler-rhetoric.md) 的「人造金句與斷奏式短句」。

### 改寫前

```text
點擊儲存。系統開始驗證。驗證通過。資料寫入資料庫。畫面顯示成功訊息。
```

### 改寫後

```text
點擊儲存後，系統先驗證欄位，通過後寫入資料庫並顯示成功訊息。
```

### 改寫前（說明段落）

```text
匯入檔案時先選擇格式。欄位對應依檔案的標題列。預覽區顯示前十筆資料。
```

### 改寫後（說明段落）

```text
匯入檔案時先選擇格式，欄位對應依檔案的標題列，預覽區顯示前十筆資料。
```
